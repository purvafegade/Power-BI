# HR Analytics & Employee Attrition Analysis

# Project Objective

The main objective of this project is to analyze employee data and present important HR insights through an interactive Power BI dashboard. It helps HR departments and management understand workforce performance, employee satisfaction and attrition patterns.


## Dataset Description

The HR Analytics & Employee Attrition Analysis project uses an HR dataset containing employee-related information. The dataset consists of five tables: Employee, Education Level, Performance Rating, Rating Level, and Satisfied Level.


## Dataset Columns

Table Name	Purpose
Employee	Stores employee-related information.
Education Level	Stores employee education categories.
Performance Rating	Stores employee performance information.
Rating Level	Stores performance rating categories.
Satisfied Level	Stores employee satisfaction categories.
